# 0002. Licence

Status: accepted (2026-11-08)

## Context
Likely users are banks, fintechs and vendors who care about patent terms. Prowide ISO 20022 is Apache-2.0
(see `docs/research.md`).

## Decision
Apache-2.0 for all code, rule packs and docs we author.

## Consequences
- Explicit patent grant; compatible with Prowide's open edition.
- Differs from the maintainer's Iris project (MIT); noted in CONTRIBUTING.
- Rule packs must not embed third-party spec text (see ADR 0003).
